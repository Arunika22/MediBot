# MediBot 🤖🩺  
An AI-powered mobile healthcare assistant built with Kotlin and Node.js, providing on-device disease prediction and medical report analysis.

## 🌟 Features

- **🧠 Symptom Checker (On-Device):**  
  Predicts top 5 possible diseases based on selected symptoms using a TensorFlow Lite model.

- **📄 Medical Report Analysis:**  
  Upload PDF or image-based medical reports. The backend extracts and returns structured values (e.g., haemoglobin, sugar level).

- **📴 Offline Support:**  
  Symptom-based disease predictions run entirely on-device without internet access.

- **✅ Symptom Selection UI:**  
  Smooth and scrollable interface displaying 132 symptom checkboxes for quick selection.

- **💊 Medicine Reminders:**  
  Set daily or weekly medicine schedules with smart reminders, dosage info, and notifications. Includes calendar tracking and snooze/taken actions.

- **📅 Appointment Booking :**  
  Book appointments with doctors based on specialization, location, and availability. Includes calendar integration, reminders, and future support for secure communication.


---

## 📱 Tech Stack

| Component          | Technology             |
|-------------------|------------------------|
| **Frontend**       | Kotlin (Android)       |
| **Backend**        | Node.js + Express      |
| **ML Model**       | TensorFlow Lite (TFLite) |
| **Report Parsing** | NLP on backend   |
| **Data Format**    | JSON                   |
